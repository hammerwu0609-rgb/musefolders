# 单页音乐工作台

正式入口为 `app.py`，旧版工具保留在 `legacy_app.py`。

页面采用黑绿配色，参考 QQ 音乐的紧凑歌曲列表、绿色操作按钮和底部播放器。上方提供音乐地图、能量分区、歌词主题和收藏星图四个探索入口；右侧显示自动生成的音乐星座。下方一个输入框负责检索与本地歌单操作。

- 输入“关于爱情的歌”“睡前听的歌”检索现有收藏；连接 DeepSeek 后使用模型理解描述，歌曲仍在本机匹配。
- 输入“找睡前听的歌，建一个「今晚」歌单”或“把搜索结果建成「爱情」歌单”，创建本地歌单。
- 点击歌曲旁的加号加入歌单；歌单可以改名、移除、调整顺序、切换、试听和导出 M3U8。
- 新建歌单前会保留当前歌单。网页操作不写入 QQ 音乐账号。
- 点击星图中的歌曲可以试听；星图的横轴为节奏指数，纵轴为明亮度，颜色为活跃度。绘图区保持等尺度的正方形；星座由整个收藏自动匹配，没有手动选择星座的入口。
- 点击分享生成并下载现有 PNG 星座卡；没有公开发布、多人账号或线上社交服务。
- 顶部“管理曲库”打开独立弹窗，分为音乐来源、歌曲资料和 AI 设置。弹窗可通过右上角、Esc、点击空白处或“返回音乐库”关闭，不在主页面展开设置。密钥只留在服务端网页会话中，不传给自定义前端。

## 地区资料

地球几何数据随项目离线提供，支持拖动、方向键旋转、普通滚轮缩放（无需 Ctrl）、缩放按钮和重置。滚轮只在地球上缩放，其他位置正常滚动页面。地图显示有数据的国家／地区、曲目数及可点击标记，选择地区即可筛选真实收藏并试听。

地区通过 MusicBrainz 艺人搜索和详情接口补充，保存来源链接；同名身份不确定、地区字段缺失或接口失败时保留待补充。音乐作品存在跨国合作，因此目前统一按**首位署名艺人档案中的关联地区**归类；这个字段不代表歌词语言，也不保证等同于国籍、出生地或歌曲发行地。

管理弹窗的“歌曲资料 → 补充地图地区”可继续补全。命令行也可运行 `.venv\Scripts\python.exe scripts\enrich_artist_regions.py`。成功条目缓存于 `artifacts/artist_regions.json`，查询状态存于 `artifacts/artist_regions_audit.json`。

可由后续元数据接入流程生成 `artifacts/artist_regions.json`，键与歌曲档案里的歌手名称一致：

```json
{
  "歌手名称": {
    "country": "392",
    "label": "日本",
    "source": "https://提供该歌手地区事实的来源页面"
  }
}
```

`country` 使用 ISO 3166-1 数字国家码；没有来源字段的条目不会用于地图。键可使用完整歌手署名或首位署名艺人名称，括号别名可复用同一已记录来源。

## 代码与本地状态

- `simple_ui.py`：导入、资料补充、设置及曲库初始化。
- `consumer_ui.py`：Streamlit 双向组件、服务端动作、真实媒体播放和现有检索服务。
- `consumer_workspace.py`：页面数据、歌单命令拆分、歌单保存和切换。
- `consumer_frontend/`：HTML、CSS、JavaScript 与离线地球依赖。
- `artifacts/playlist_drafts/`：当前歌单；`artifacts/saved_playlists/`：按名称保留的本地歌单。

音频播放通过 Streamlit 本地媒体服务提供。页面数据不包含本地文件路径；导出的 M3U8 按用户请求引用原音乐文件。
