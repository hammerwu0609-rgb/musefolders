# 曲境发布与打包说明

当前发布物是经过 Git 跟踪清单生成的**源码/Demo 包**，不是免安装的独立 Windows EXE。接收方需要安装 `uv`，解压后运行 `启动曲境.cmd`；首次启动会创建本地 Python 3.11 环境。

生成发布包：

```powershell
.\scripts\build_release.ps1 -Version "0.1.0-handoff"
```

脚本只归档当前 Git `HEAD` 中已经跟踪的文件，并生成 SHA-256 校验文件。`.gitignore` 会排除：

- 用户音乐、歌词与受保护格式；
- `artifacts` 分析档案、缓存、草稿和本地路径；
- API Key、`.env` 和 Streamlit secrets；
- `.venv`、测试缓存与构建目录；
- 可选的 fastText `lid.176.ftz` 模型。

源码包中保留 MusiCNN 与 YAMNet 模型，供本机听感画像和主要声源 Demo 使用。发布前必须继续保留 `models/MODEL_ATTRIBUTION.md` 与 `models/MUSICNN_LICENSE.txt`，并完成 YAMNet TFLite 权重分发条款的最终书面核验。

真正面向非技术用户的 Windows 安装包仍是待办。建议在独立构建机上验证 PyInstaller 或 Nuitka 的 one-folder 方案，重点覆盖 Streamlit、MediaPipe、ONNX Runtime、模型资源路径、中文目录、杀毒误报、升级和卸载；达到交接文档的干净机器验收条件后，才能称为“独立桌面安装包”。
