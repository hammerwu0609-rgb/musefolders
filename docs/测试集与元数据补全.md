# 测试集与元数据补全

运行：

```powershell
.venv\Scripts\python.exe scripts\build_test_sets.py
```

`artifacts/test_sets.json` 包含已经匹配到可用歌词的歌曲、较高把握的纯音乐候选，以及需要人工试听确认的歌曲。缺少歌词不会自动被当作纯音乐；确认纯音乐时应记录试听结果。Live、Remix、翻唱和电影原声也要确认歌词对应当前录音版本。

运行：

```powershell
.venv\Scripts\python.exe scripts\enrich_metadata_musicbrainz.py
```

结果写入 `artifacts/metadata_enrichment.json`。脚本只读查询 MusicBrainz，保存候选录音、艺术家、专辑和发行日期，不修改音频、歌词或 `collection_plan.json`。同名歌曲、不同版本和翻唱需要人工复核后才能成为正式元数据。

当前样本运行结果：95 首中 33 首返回候选，60 首没有匹配，2 首请求异常。第一轮人工只需核对 15—20 首歌词歌曲和 5—10 首纯音乐。

建议确认字段：歌曲版本、音频来源、歌词来源或“确认纯音乐”、专辑、发行年、语言、稳定 ID、主题标签和测试用途。
