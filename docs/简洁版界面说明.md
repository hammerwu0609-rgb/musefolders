# 曲境简洁版

默认入口为 app.py。原工程工作台保留在 legacy_app.py，不在普通用户的界面中展示。

## 用户流程

首次选择音乐文件夹并导入。再次启动自动恢复已保存的本地曲库；“管理曲库”可以更换目录并重新分析。

找歌：输入描述或点击示例，查看结果和依据，试听并加入歌单。底部歌单可移除、调序、命名并下载 M3U8，有歌曲时显示固定快捷入口。播放清单引用原始文件，移动原文件后需要更新曲库。

我的音乐画像：查看收藏数量、时长和歌词覆盖；从听感或主题分类直接跳回歌曲结果；自动匹配音乐星座并生成本地分享 PNG。少于 12 首不同录音时显示明确提示。

## 简化范围

移除默认界面中的四张地图、独立审查步骤、Song Path、Song Alchemy、专业指标筛选、编码表、接口扩展和手动星座选择。保留后台分析和缓存，实现复用，不重复分析音频。歌词目录默认跟随曲库并递归匹配。

## 能力边界

检索使用同一份带证据来源的逐曲标签档案；界面会显示把输入理解成了哪些条件。可选 AI 只负责将用户的查询翻译为固定字段，启用后才发送用户输入的那句话；具体匹配在本机完成。歌词主题仍是关键词线索，尚不支持任意歌词语义。主题分组可重叠；歌词缺失的歌曲不补造主题。原始流派未核实，不参与画像。技术说明见[逐曲标签与自然语言契约](./逐曲标签与自然语言契约.md)。

星座根据既有节奏、明亮度点阵自动匹配，为基础声学趣味轮廓，不表示人格；仅保存点阵及生成图片，不上传音乐、歌词或路径。

## 启动与维护

在项目根目录运行 `.\run_local.ps1`，访问 http://127.0.0.1:8501。

维护旧工作台：`.venv\Scripts\python.exe -m streamlit run legacy_app.py --server.port 8502`。

测试覆盖旧工作台及新默认入口；新增测试验证导入错误、搜索、加入／移除、歌单下载入口、画像和主题跳转。真实 95 首曲库已用浏览器验证爱情查询返回 9 首、画像和分享卡生成。
