# 曲境：首次导入与本地音乐读取

## 评委在线体验

1. 进入网页，看到空音乐库和导入入口。
2. 点击「导入体验音乐包」。音乐、歌词、地区、平台资料与 AI 标签已在服务器上，评委无需下载再上传。
3. 页面显示实际文件读取、歌曲与资料校验进度。
4. 导入完成后显示歌曲数、复用的分析数及歌词情况，再进入原有探索工作台。
5. 按音乐星球 → 听感空间 → 主题河流进行探索、试听、检索和创建歌单。
6. 「管理曲库 → 音乐来源 → 重新体验导入流程」回到空库入口；不删除云端共享音乐。

云端共享 `demo_library` 保留原样。每位访客使用独立临时工作区，只有点击导入才生成本次使用的收藏档案；首次进入不加载现成曲库。新会话从空库开始，已有会话在重新体验前保留本次状态。

现成音乐包复用已有声学分析及歌词 AI 标签。进度文案明确区分读取、校验与重新分析，不用假进度模拟重新测量音频。未知地区仍显示待补充，纯音乐不强行补歌词。

## 本地音乐

- 本地入口仍是 `app.py` / `run_local.ps1`，已有持久音乐库继续恢复。
- 「管理曲库 → 音乐来源」保留文件夹选择及路径输入，执行原有本地音频分析。
- 统一的「选择音乐文件或音乐包」入口支持音频、同名 LRC／TXT 歌词及 ZIP，自动识别处理方式。音频与歌词可多选，ZIP 每次导入一个，可保留子目录结构。
- 原始音频不修改。文件上传到运行应用的机器：本地版在本机，网页版在当前访客的服务器临时工作区。
- 新音频实际分析节奏、明亮度等声学特征。歌词故事可从已有标签或词汇匹配读取；新增外部 AI 分析仍需主动配置并调用模型。艺人地区不会从歌词语言推断。
- 可选择「重新分析包内音频」，重新测量声学特征并保留已校验的歌曲资料关联。整库分析可能需要数分钟；未成功的音频单独报告，不伪造结果。
- 受保护格式不解密。可选乐器模型未配置时该能力保留不可用；基础音频分析仍可使用。

## 完整音乐包与部署准备

数据源为同伴交接的版本 003 对应便携数据。音乐包包含音频、歌词、收藏计划、地区、平台、AI 标签和人工确认；附每个文件的 SHA-256 校验清单。仅打包数据白名单，不包含 API 密钥或登录凭据，不加入 Git。

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe scripts/package_experience_library.py --bundle demo_library --output demo_library/experience.zip
```

`demo_library/experience.zip` 供首页的可选下载按钮使用；在线按钮仍直接读取服务器原有 `demo_library`，不会把服务器数据移走或要求评委上传这个 ZIP。

ZIP 上传总大小限 512 MB，解压总大小限 1 GB、2000 个文件。文件名、目录、重复项、链接、加密项、音频哈希及跨资料关联均在导入时检查；失败的导入不替换当前使用的音乐库。已成功替换的本地资料保存在被 Git 忽略的 `library_backups/`，上传音频保存在 `library_imports/`。

代码修改和部署是两个步骤。部署仍使用原服务、7860 端口与 0–1 副本；GitHub 推送不更新线上。上线前应明确授权、实际检查导入及播放流程，并确认发布状态与流量。
