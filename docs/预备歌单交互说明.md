# 我的预备歌单：交互与兼容说明

## 当前规则：2026-10-08 新版

全库复选框只形成临时待加入选择，覆盖前提示；选中歌曲随最新单曲、板块或搜索切换，均无复选框。只有明确加入后，歌曲才进入预备歌单；成功加入后从当前选择中移除。

抽屉工具栏提供“清空歌单”，一键清空当前预备歌单并保存，保留歌单名称；20 秒内可“撤销清空”。空歌单时按钮禁用。

预备歌单统一逐曲显示并标注加入来源，支持逐曲删除、20 秒内撤销和排序。删除对当前歌单的所有来源生效，之后可重新加入。唱片入口为可拖动悬浮球，“管理曲库”已更名为“管理曲境”。

完整新版需求、设计与验收见 `specs/selection-and-prepared-playlist-v2/`；最终回归 193 项通过。

### 歌单与音频导出

**导出 M3U8 为主入口，云端优先推荐。** M3U8 只包含歌曲顺序和播放路径，不包含音频；播放需有对应歌曲文件。音乐 ZIP 为补充可选项，不会代替 M3U8。

“导出音乐 ZIP”打包当前预备歌单的实际音频，按歌单顺序编号、按音频指纹去重。已有有效 MP3 原样复制；其他支持的音频通过 FFmpeg 转为 MP3，不修改原曲库。ZIP 解压后得到单个歌单文件夹，内含 MP3、使用相对路径的 M3U8 和导出说明。

歌名或歌手资料不完整时，使用文件名／未知歌手作为替代名称，并在界面与说明中提示；只有资料没有音频、录音丢失、文件损坏或转换失败时，明确提示未导出的歌曲及原因。没有任何有效音频时拒绝生成空包；部分可导出时输出有效歌曲并列出遗漏。音乐包容量上限为 512 MB，超过时提示分批导出。

本次本地验证：95 首曲库导出约 343 MB ZIP；验证 MP3 复制内容不变、FLAC 转 MP3、去重、缺失录音及元数据提示和真实音频解码。页面验证 M3U8 为主按钮、ZIP 为次按钮，预备歌单导出可生成音频包。现有 193 项回归通过；较长的 Windows 临时测试路径曾导致失败，使用较短的临时目录后通过。

### 声音星图缩放

声音星图支持 1–12 倍缩放：使用加减按钮或 Ctrl＋滚轮；通过方向按钮或 Shift＋拖动移动视图，重置按钮恢复全图。普通拖动继续框选；点间距随缩放拉开，圆点大小保持不变。缩放、平移和重置不会改变已选歌曲或预备歌单。

本次本地浏览器检查通过：按钮缩放和平移、重置、Ctrl＋滚轮、Shift＋拖动、放大后框选、选中集合保留、点选不自动播放，以及 390px 窄屏控件。JavaScript 语法与差异格式检查通过；本次未重跑上述完整回归。

**以下保留上一轮实现和验收历史，其中复选框立即加入、板块卡片回看、按来源分别移除等规则已被新版替代。**

## 三个独立区域

- **全库歌单**：显示已导入且拥有声学分析结果的歌曲，探索筛选不改变全库范围。QQ 仅资料记录不会被伪装成已分析音乐。
- **选中歌曲**：显示当前单曲、地区、氛围、歌词主题、星图框选、搜索结果或已加入板块的快照。点击只改变选择，播放使用独立按钮。
- **我的预备歌单**：左下角唱片盒展开独立抽屉；位置根据播放器实际高度调整，在手机上也避免重叠。保留新建、改名、切换、排序、播放及导出。

## 加入与移除

复选框仅表示单独加入：勾选即加入，取消即移除单曲来源，每行的加号执行相同的加入操作。整板块通过独立按钮加入，保存完整匹配集合，包含列表中尚未显示的歌曲。

板块卡片保存名称、来源、特征、条件及加入时的成员快照。点击卡片在选中歌曲中展开，之后的筛选或资料更新不会悄悄重算该快照。缺失音频通过指纹重新定位，找不到时提示待找回。

单曲和板块分别管理。一首歌可同时属于多个板块与一个独立单曲条目；取消单曲勾选不修改板块，删除板块不影响其他来源。播放及导出按来源条目顺序展开后以音频指纹去重。

加入动效在服务端保存成功且确实新增来源后触发，重复加入和保存失败不播放成功动效。启用减少动态效果时改为静态高亮和文字反馈。

## 旧数据

草稿格式升级为版本 2。`entries` 保存来源条目及快照，`items` 保留为去重后的兼容视图。版本 1 的旧歌单迁移为独立单曲，保留名称、顺序、排除项和归档文件标识，不猜测旧数据已经丢失的板块来源。

默认界面名称更新为“我的预备歌单”，用户自定义名称保留。自然语言同时接受“歌单”和“预备歌单”。M3U8 输出仍是普通歌曲清单，不包含板块分组或服务器路径（云端演示导出）。
